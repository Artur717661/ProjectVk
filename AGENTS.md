# AGENTS.md

## Project

Photo Analysis Service — backend для загрузки фотографий, постановки задач на
обработку и сохранения результатов анализа.

На текущем этапе реализуется вертикальный срез первых двух воркшопов:
FastAPI, PostgreSQL и MinIO. Kafka, worker и отдельный analyzer описаны в
архитектуре и будут подключаться позже.

## Stack

- Python 3.12
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- MinIO
- Docker Compose
- Pytest
- OpenAPI
- Protobuf-контракт для будущего analyzer

## General Rules

- Делать изменения небольшими логическими шагами.
- Не добавлять инфраструктуру и фреймворки без понятной причины.
- Не смешивать HTTP-обработчики, SQL и работу с MinIO в одном файле.
- Обновлять README и документацию, если меняется запуск или API.
- После изменений запускать тесты и указывать команды проверки.
- Объяснения в коде писать коротко и на русском языке.

## Expected Workflow

1. Сначала зафиксировать короткий план.
2. Сделать одну небольшую часть.
3. Проверить её тестами или ручным запросом.
4. Обновить документацию, если это необходимо.
5. Только после этого переходить к следующей части.
